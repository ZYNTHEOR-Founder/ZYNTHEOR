# ZYNTHEOR Core System

ยินดีต้อนรับสู่ระบบสถาปัตยกรรมอัตโนมัติและโครงสร้างพื้นฐาน AI ของ **ZYNTHEOR**

## 🌐 ระบบการทำงานหลัก (System Architecture)
- **Autonomous Workflows:** ระบบตรวจสอบและรันอัตโนมัติผ่าน GitHub Actions
- **Security & Audit:** การป้องกันสาขาและการตรวจสอบความสอดคล้องของโค้ดแบบเรียลไทม์
- **Asset Hub:** คลังทรัพยากรกราฟิกและเอกสารมาตรฐาน (`docs/`)

- `docs/AGENTS_AUDIT.md` — บันทึกผลการตรวจสอบระบบอัจฉริยะ
